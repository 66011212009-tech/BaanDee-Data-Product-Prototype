# ระบบช่วยตรวจสอบความพร้อมของสินค้าแต่ละสาขา

**Phase 1: การกำหนดผู้ใช้และปัญหา**

**1. ผู้ใช้หลักคือใคร** พนักงานขายหน้าร้าน (Store Sales Staff) และพนักงานบริการลูกค้า (Customer Service) ของ BaanDee Living

**2. ผู้ใช้กำลังพยายามทำงานอะไร** ตรวจสอบสถานะและจำนวนสต็อกสินค้าที่ลูกค้าต้องการจากสาขาอื่นๆ เพื่อแนะนำให้ลูกค้าเดินทางไปซื้อยังสาขาใกล้เคียงที่มีของ หรือเพื่อยืนยันการจองและสั่งโอนย้ายสินค้าข้ามสาขาให้ลูกค้าได้อย่างแม่นยำ

**3. ปัญหาในกระบวนการปัจจุบันคืออะไร** ข้อมูลสต็อกของแต่ละสาขาอาจไม่อัปเดตแบบเรียลไทม์ หรือพนักงานไม่สามารถแยกแยะได้ว่าสินค้าที่มีในระบบนั้น "พร้อมขาย" จริงหรือไม่ (เช่น อาจเป็นสินค้าตัวโชว์ สินค้าชำรุด หรือสินค้าที่ถูกจองไว้แล้วแต่ยังไม่ตัดสต็อก) ทำให้พนักงานต้องเสียเวลาโทรศัพท์เช็คสาขาอื่นทีละแห่ง ซึ่งทำให้ลูกค้ารอนานและเสียโอกาสในการขาย

**4. ต้นแบบจะช่วยให้กระบวนการดีขึ้นอย่างไร** ระบบจะดึงข้อมูลจากหลายแหล่ง (เช่น ฐานข้อมูลคลังสินค้า ข้อมูลระบบจอง และข้อมูลสาขา) มาประมวลผลในหน้าจอเดียว เพื่อแสดง "จำนวนสินค้าที่พร้อมขายจริง" (Available to Promise) โดยอัตโนมัติ พร้อมแสดงเวลาที่ข้อมูลอัปเดตล่าสุดและหลักฐานประกอบ ช่วยให้พนักงานไม่ต้องเดาข้อมูลหรือเสียเวลาโทรเช็ค และสามารถให้คำตอบลูกค้าได้อย่างมั่นใจและรวดเร็วขึ้น

**5. ผลลัพธ์ใดเป็นเพียงสมมติฐานที่ยังต้องทดลองกับผู้ใช้จริง**

* พนักงานจะเกิดความเชื่อมั่นในตัวเลขที่ระบบคำนวณให้ จนเลิกพฤติกรรมการโทรศัพท์ไปสอบถามยืนยันกับสาขาปลายทาง
* รูปแบบการแสดงผลข้อมูล (UI) เข้าใจง่าย รวดเร็ว และเหมาะสมกับสภาพแวดล้อมการทำงานจริงที่พนักงานต้องใช้งานขณะยืนคุยกับลูกค้าหน้างาน
